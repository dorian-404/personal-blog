# personal-blog

Site personnel — écriture, notes et expériences sur le code et les interfaces.

**→** [personal-blog-nu-eosin.vercel.app](https://www.mishaeldorian.com/)

## Stack

Next.js · Tailwind v4 · MDX · Vercel

## Dev

```bash
pnpm install
pnpm dev
```

## Contenu

Les articles sont des fichiers `.mdx` dans `app/blog/`.

## Variables d'environnement

Copier `.env.example` en `.env.local` et remplir les valeurs.

```bash
cp .env.example .env.local
```
